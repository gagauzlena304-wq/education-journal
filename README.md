# Учебный журнал

Решение варианта № 1 для образовательного учреждения. Приложение работает локально в браузере. Сервер и база используют стандартную библиотеку Python и SQLite.

## Скачать версию

Откройте [последний релиз](https://github.com/gagauzlena304-wq/education-journal/releases/latest) и в разделе **Assets** скачайте `education-journal-v1.0.0.zip`. Распакуйте архив полностью в папку, в которую у вас есть право записи, например `Документы\education-journal`. Запускайте приложение из распакованной папки.

В архив включены приложение, демонстрационные CSV, SQL-схема, ER-диаграмма, инструкция и тесты. Версия `1.0.0` требует установленного Python.

## Установка и запуск в Windows

1. Установите Python 3.11 или новее с [официального сайта Python](https://www.python.org/downloads/). При установке включите Python launcher или добавление Python в PATH. Требуется SQLite 3.37 или новее, который входит в стандартную установку актуального Python.
2. Откройте распакованную папку и дважды щёлкните **Start.cmd** или **Запустить.cmd**. Скрипт проверит Python и SQLite, запустит сервер и откроет журнал в браузере.
3. Если браузер не открылся, перейдите на [127.0.0.1:8765](http://127.0.0.1:8765/).
4. Держите окно сервера открытым во время работы. Для остановки нажмите Ctrl+C в этом окне.

Для запуска через cmd перейдите в папку приложения и выполните следующую команду. Замените пример пути на путь к своей распакованной папке.

```cmd
cd /d "C:\Users\User\Documents\education-journal"
Start.cmd
```

## Запуск в Linux и macOS

Установите Python 3.11 или новее с модулем `sqlite3` и SQLite 3.37 или новее. В терминале перейдите в распакованную папку приложения.

```sh
cd ~/Downloads/education-journal-v1.0.0
python3 app.py --open
```

Приложение использует стандартную библиотеку Python. Установка пакетов через pip не требуется. Интернет нужен для скачивания приложения и Python. После установки журнал работает локально.

## Данные и повторный запуск

При первом запуске рядом с `app.py` создаётся файл `education.sqlite3` и загружаются CSV из `data`. При последующих запусках журнал открывает сохранённую базу. Включённые CSV содержат демонстрационные данные.

Чтобы сделать резервную копию, остановите сервер и скопируйте `education.sqlite3` в другую папку. Для восстановления остановите сервер и поместите сохранённую копию в папку приложения. При обновлении распакуйте новую версию в отдельную папку и перенесите туда свою базу.

Сервер слушает `127.0.0.1`, поэтому каждый пользователь работает со своей локальной копией. Система рассчитана на учебное использование на одном компьютере.

## Решение проблем запуска

- Если `python` выводит только слово `Python` или открывает Microsoft Store, используйте **Start.cmd**. Он проверяет доступные интерпретаторы перед запуском. Для ручного запуска попробуйте `py -3 app.py --open` или `"%LOCALAPPDATA%\Python\bin\python.exe" app.py --open` в cmd.
- Если Python не найден, установите его с официального сайта, затем заново откройте cmd или **Start.cmd**.
- Если порт 8765 занят, запустите `Start.cmd --port 8766` в cmd и откройте `http://127.0.0.1:8766/`.
- Если база недоступна для записи, перенесите всю папку приложения в «Документы» и повторите запуск.

## Модель данных и импорт

Таблицы приведены к третьей нормальной форме. Названия групп, курсов и платёжных типов хранятся в соответствующих таблицах. Платёж ссылается на начисление, из которого система получает студента, тип и наименование. Оценки и посещаемость связывают студента и занятие составным первичным ключом. Внешние ключи включаются для каждого соединения. Суммы хранятся целыми числами в сотых долях лея. Остаток рассчитывается как сумма начисления за вычетом всех платежей по нему. Триггеры контролируют переплату и уменьшение начисления ниже уже внесённой суммы.

В папке задания были только условия в Word. В `data` включены демонстрационные CSV со связанными идентификаторами. Импорт `import_csv` читает файлы в порядке зависимостей и записывает их одной транзакцией. После успешной загрузки повторный запуск использует существующие данные. Для проверки импорта с нуля укажите новый файл базы. Свой каталог CSV можно передать через `--data-dir`. Имена файлов и заголовки должны соответствовать примерам.

```powershell
python app.py --init-only --db test-import.sqlite3 --data-dir data
```

## Алгоритм рейтинга

1. Прочитать оценки студента из журнала и вычислить их среднее арифметическое. Если оценок ещё нет, взять средний балл, введённый в карточке. При отсутствии обоих источников доступ составляет 0%.
2. Определить процент по неокруглённому среднему. Для отображения балл округляется до двух знаков.

| Средний балл | Рейтинг и доля доступных курсов |
| --- | ---: |
| Менее 3,5 | 0% |
| От 3,5 до 4,0 без верхней границы | 25% |
| От 4,0 до 4,5 без верхней границы | 50% |
| От 4,5 до 5,0 включительно | 100% |

3. Отсортировать бонусные курсы по установленному в базе приоритету. Показать первые `⌊количество курсов × рейтинг / 100⌋` курсов. В демонстрационных данных четыре бонусных курса, что даёт 0, 1, 2 или 4 доступных курса.

## Расчёт стоимости

`calculate_tuition(db, course_id, material_type_id, hours, unit_price, partner_id, adjustment)`

Итог = часы × цена за час × (1 + корректировка / 100). Отрицательная корректировка задаёт скидку, положительная задаёт наценку. При пустом поле используется ставка выбранного партнёра или 0% без партнёра. Введённая ставка заменяет ставку партнёра. Итог округляется до сотых долей лея. Например, 10 часов по 100 лей со скидкой 15% стоят 850 лей.

## Тесты

Откройте cmd в распакованной папке приложения и запустите проверки.

```cmd
py -3 -m unittest -v
```

Если команда `py` отсутствует, используйте `python -m unittest -v` либо полный путь к установленному Python. В Linux и macOS выполните `python3 -m unittest -v`.

Тесты используют временные базы. Покрыты загрузка и откат импорта, внешние ключи, границы рейтинга, корректировки стоимости, контроль переплат и HTTP-сценарии работы с формами и фильтрами. При успешной проверке в конце появляются `Ran 7 tests` и `OK`.
