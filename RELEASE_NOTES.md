# Учебный журнал 1.0.0

Первый выпуск локальной системы управления учебным процессом.

- Просмотр, добавление и редактирование студентов и преподавателей.
- История оценок и посещаемости, расписание занятий.
- Расчёт рейтинга и доступных бонусных курсов.
- Начисления, оплаты, задолженность и фильтры истории платежей.
- Учёт партнёров и расчёт стоимости обучения со скидкой или наценкой.
- SQLite, демонстрационные CSV, SQL-схема и ER-диаграмма в PDF.
- Семь автоматических тестов и инструкция установки в README.md.

Скачайте `education-journal-v1.0.0.zip`, распакуйте архив и откройте `README.md`. В Windows установите Python 3.11 или новее и запустите `Start.cmd`. В Linux и macOS выполните `python3 app.py --open` из папки приложения. Дополнительные пакеты Python не требуются.

Данные сохраняются локально в `education.sqlite3`. При первом запуске база создаётся из демонстрационных CSV. В архиве поставляются исходники, для запуска нужен Python.

Файл `SHA256SUMS.txt` содержит контрольную сумму ZIP-архива.
